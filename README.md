## 📌 Problem Statement

### Problem Statement 1 – The Last-Minute Life Saver

Students, professionals, and entrepreneurs often struggle to manage multiple deadlines, assignments, meetings, and personal commitments. Traditional productivity tools mainly rely on passive reminders that are easy to ignore.

**DeadlineGenie** solves this problem by acting as an intelligent AI productivity companion that helps users plan, prioritize, and complete their work before deadlines are missed.

---

## 📖 Project Overview

DeadlineGenie is an AI-powered productivity companion designed to help users stay organized and productive. Instead of simply reminding users about upcoming deadlines, the application intelligently analyzes tasks, priorities, deadlines, goals, and habits using Google's Gemini AI.

Based on this analysis, DeadlineGenie generates personalized productivity recommendations, suggests the best order to complete tasks, provides wellness tips to prevent burnout, and motivates users through short AI-powered focus challenges.

The application follows an **offline-first architecture**, ensuring that users can continue managing their tasks even without internet connectivity. Personal data is securely stored using LocalStorage, while AI recommendations are generated through a secure Express backend integrated with Google Gemini AI.

## ⚙️ How It Works

1. Users create tasks, goals, and daily habits.
2. React stores all information securely using LocalStorage.
3. When users click **Ask DeadlineGenie**, task details are sent to the Express backend.
4. The backend securely communicates with Google Gemini AI.
5. Gemini analyzes deadlines, priorities, goals, habits, and workload.
6. AI generates personalized productivity recommendations.
7. The dashboard updates instantly with smart task prioritization and productivity guidance.
